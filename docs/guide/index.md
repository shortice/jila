# Introduction

Jila - the experiemental framework for building applications (from PC to mobile devices) using Lua.

Its combine SDL3, Dear ImGui, LuaJIT and some other libs in one tool. 

And some other features:
* You can(!) disable some modules, if you don't need this;
* You can write own modules in C++;
* One codebase and language (if you don't planning extend this API). All you need for comfort developoment is:
    * Understand Platform (and this lib) specific limitations;
    * Understand Lua language;
    * Understand there lib API's;
    * And basic programming knowledge:)
