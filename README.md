# jila

Experimental WIP framework for creating Lua application for Android/Windows/Linux.
Built on SDL3 + DearImGui and other libs (see in src/external).

# How build?

Clone this repo and all submodules. 
Execute
```sh
cmake ./src -B ./build
cmake --build ./build
```

Then build:
```sh
cmake --build ./build
```

And run example app:
```
./build/app/main ./examples/sample_app
```
